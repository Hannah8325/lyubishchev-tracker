# 柳比歇夫时间账本 · Obsidian 插件

把时间账本的记录接进 Obsidian，**双向同步**：

- **读**：网页版「导出 → Obsidian（.json）」下载的 `时间日志-XXXX-XX-XX.time.json`，放入本插件设置的同步文件夹（默认 `时间账本/`），插件自动合并，生成周 / 月分类饼图统计。
- **写**：在统计视图里直接改类别名称和颜色（记录归档也可扩展），修改写回 `sync.time.json`；网页版再导入该文件即完成双向闭环。
- **写日记**：命令「把今日时间日志写入日记」把今日时间线表格追加到当天日记（找不到日记则生成独立文件）。

## 安装（评委 / 用户）

方式一（推荐）：把本目录复制到你的 Vault：`你的仓库/.obsidian/plugins/lyubishchev-time-log/`，重启 Obsidian → 设置 → 第三方插件 → 关闭安全模式 → 启用「柳比歇夫时间账本」。

方式二：通过 BRAT 插件安装（填入仓库地址）。

## 使用

1. 网页版「导出 / Obsidian」页 → 下载 `.time.json`。
2. 在 Vault 里新建 `时间账本` 文件夹，把文件丢进去。
3. 点左侧边栏 🕒 图标（或命令面板「打开时间账本统计视图」）。
4. 切换本周 / 本月，查看饼图；点类别名可直接改名，颜色可直接改。

## 开发说明

纯 JavaScript 编写，无需构建步骤。`main.js` 直接引用 Obsidian API（`obsidian` 模块由 Obsidian 运行时提供）。
