# 柳比歇夫时间账本（Lyubishchev Time Ledger）

> 知乎黑客松参赛作品 · 基于柳比歇夫时间统计法的时间管理工具

## 一句话介绍

**像记账一样记时间**：PC 桌面悬浮窗一句话开始计时，结束后选类别归档；自动生成课程表式的「今日时间轴」和周/月分类饼图，帮助用户找到时间黑洞、持续优化；数据可双向接入 Obsidian，进入个人知识库闭环。

## 已确认的产品决策

| 决策点 | 结论 |
|---|---|
| 计时模式 | 单线程（同时只记一件事，统计永不重叠） |
| 类别体系 | 结束事件时选类别；类别 = 一级科目，事件名 = 明细，统计按类别聚合 |
| 提醒/目标 | 不做超限提醒 |
| 睡眠 | 记录，跨午夜自动处理 |
| 记录方式 | 纯手动，不做自动行为追踪（隐私友好） |
| Obsidian | 双向同步（导出 .time.json → 插件读；插件改类别 → sync.time.json → 应用导入） |
| 账号/云端 | 正式版做账号+云端同步（用 Supabase 等 BaaS，**无需任何硬件**） |
| 用户说明书 | 独立文档《用户说明书.md》，程序内有「？使用说明」入口 |

## 差异化（vs aTimeLogger / 时间块等已在售产品）

1. **PC 悬浮窗工作流**：桌面常驻小窗，输入即计时，不打断工作流（Demo 内为可拖拽网页悬浮窗，正式版用 Electron/Tauri 实现置顶+开机自启）。
2. **先记后分**：结束事件时才选类别，把记录摩擦降到最低。
3. **AI 能力**（待接入）：自然语言补录（"下午3点到4点开会"自动成记录）+ AI 周报复盘建议 —— 对应评审"AI 场景价值"。
4. **Obsidian 双向联动**：时间数据进入知识库，可编辑回写。

## 目录结构

```
lyubishchev-tracker/
├── index.html            # 网页 Demo（单文件：悬浮窗/时间轴/周月饼图/类别/导出）
├── serve.js              # 极简静态服务器（支持 --host/--port 参数）
├── package.json          # npm run dev
├── 用户说明书.md          # 独立用户说明书（提交材料）
└── obsidian-plugin/      # Obsidian 插件（纯 JS，免构建）
    ├── manifest.json
    ├── main.js
    └── README.md
```

## 本地运行

```bash
npm run dev        # 默认 127.0.0.1:7100，可传 -- --port 8000
```

## 路演演示脚本建议（3 分钟）

1. （30s）悬浮窗输入「写路演 PPT」回车 → 计时中；
2. （30s）切换到今日时间轴，展示演示数据的一天；
3. （20s）点结束 → 选「深度工作」→ 时间轴新增色块；
4. （40s）统计页：周/月饼图 + 洞察卡片（环比、睡眠均值、优化建议）；
5. （30s）类别页改名/改色，演示统计跟着类别走；
6. （30s）导出 Markdown → 展示 Obsidian 插件读取 .json 的饼图；改类别名写回 sync.time.json；
7. （20s）收尾：AI 补录/复盘在正式版的规划。

## 路线图

桌面客户端（自启+置顶+全局快捷键）→ AI 补录与复盘 → 账号云端同步（Supabase）→ iOS/Android。

## 合规与隐私

Demo 数据仅存浏览器 localStorage；纯手动记录，不采集任何用户行为数据。
