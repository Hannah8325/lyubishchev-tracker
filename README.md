# 柳比歇夫时间账本

面向时间记录与日常复盘的网页原型，附 Obsidian 插件。已有版本曾用于知乎黑客松 2026；创新训练申报时应如实说明前期成果与新增研究任务。

## 已实现的功能

- 网页内悬浮计时，结束后分类；刷新恢复正在进行的计时。
- 时间轴、周/月分类统计，跨周期记录只计入周期内的时长。
- 中文规则补录：解析常见时段和时长，用户确认后保存。未指定时刻为估计值。
- 本地规则复盘；可选 Moonshot 接口复盘及追问（需要用户自己的有效密钥和可访问的接口）。
- 默认空白个人账本；独立演示账本，模拟数据不会写入个人账本。
- 今日 Markdown 日志、全部记录 JSON 导出、JSON 导入合并。
- Obsidian 插件读取导出文件、展示统计、修改类别、写回同步文件，并将时间日志追加到笔记。

## 功能边界

这是网页内悬浮窗，不能在其他应用之上保持置顶。
Obsidian 数据交换需手动导出、复制文件和导入，不是实时云同步。
自然语言补录使用本地规则，不是大模型抽取。
知乎登录、知乎搜索/直答、内容发布、云账号、跨设备同步、桌面端和手机 App 尚未实现。
统计只覆盖已记录活动，不代表完整生活时间，也不能据此认定学习效率或健康状况。

## 使用

安装 Node.js 后，在项目目录运行：

```sh
npm run dev
```

访问终端显示的本地地址。也可直接打开 index.html；浏览器剪贴板等能力可能受到限制，建议本地服务运行。
GitHub Pages 需要仓库管理员在设置中启用，仓库公开不等于网站已经发布。

第一次使用为空白个人账本。点击“查看演示”体验模拟数据，再点击“返回个人账本”。
计时中或待分类时不能切换账本。“清空当前账本”只清空当前模式的数据，操作前请先导出备份。
旧版本已存在的数据原样保留；旧版自动生成的模拟记录无法可靠自动识别，首次升级请自行检查，备份后再清理。

## 数据和在线复盘

数据保存在当前浏览器 localStorage，不自动上传，不跨设备同步；清理浏览器数据可能造成记录丢失。
JSON 导出包含全部记录，是备份方式；Markdown 仅导出今天。
没有密钥时规则复盘在本机完成。启用在线复盘时，当前周期的分类统计、事件名称样例、追问内容会发送给 Moonshot。
API 密钥只保留在当前页面内存，刷新后重新输入；升级会清除旧版保存在 localStorage 中的密钥。
不要在事件名称或追问中输入敏感信息。接口失败时降级到本地规则版，不能把规则结果描述成大模型生成。

## 创新训练可开展的工作（尚未完成）

研究“先记录后分类”和自然语言补录是否能降低大学生的记录负担。
可以用小规模自愿试用比较操作耗时、补录纠正次数、持续使用情况和反馈。
试用过程需说明收集范围并征得参与者同意，研究报告使用匿名汇总，不收集私人事件正文。
目前没有验证其提高学习效率的证据，不应预填实验结论或使用演示数据代替实测。
